## 참가자를 모집할 때

조건은 실제 사용자와 비슷한 사람이다. 사용자군마다 따로 모집한다. 아래는 일반 경향이며 가격 수치는 쓰지 않았다.

| 방식 | 쓰는 때 | 주의 |
|---|---|---|
| 유료 패널, 플랫폼 | 빨리 모아야 하고 조건 필터가 필요할 때 | 비용이 든다. 요령이 붙은 참가자일 수 있다 |
| 기존 사용자 | 실제 사용 맥락을 보고 싶을 때 | 모집에 시간이 든다. 이미 익숙해서 첫 사용 문제를 놓친다 |
| 지인, 주변 | 파일럿, 급한 점검 | 호의적이라 불편을 덜 말한다. 본 세션에는 쓰지 않는다 |

## 과업을 쓸 때

과업 시나리오는 세 가지를 지킨다. 현실적인 목표일 것, 행동을 시킬 것, 단서를 주지 않을 것이다.<Ref n={4} /> 인터페이스 용어나 단계 지시를 넣으면 답을 알려주는 셈이다.<Ref n={4} /> 과업은 한 번에 하나씩 서면으로 주고, 참가자가 직접 소리 내어 읽게 한다.<Ref n={5} />

| 나쁜 과업 | 고친 과업 | 이유 |
|---|---|---|
| 상단 메뉴의 내 예약에서 취소 버튼을 누르세요 | 다음 주 화요일 예약을 취소해야 합니다. 해 보세요 | 메뉴 이름과 위치가 답이다 |
| 예약 취소가 쉬운지 말씀해 주세요 | 예약을 취소해 보세요 | 행동 대신 의견을 묻는다 |
| 이 서비스를 마음대로 써 보세요 | 친구 생일 선물을 3만 원 이하로 주문해 보세요 | 목표와 맥락이 없다 |

위 문구는 가정 예시이며 특정 서비스의 것이 아니다.

## 세션을 진행할 때

세션 시작에서 평가받는 것은 제품이지 참가자가 아니라고 알려 준다. "테스트"라는 말이 불안을 만들 수 있으니 "리서치"나 "스터디"라고 부른다.<Ref n={5} />

소리 내어 생각하기는 화면을 쓰면서 생각을 계속 말하게 하는 방법이다. 시작할 때 이렇게 안내한다.

- 보이는 것, 하려는 것, 헷갈리는 것을 그대로 말해 달라고 한다.
- 정답이 없고 잘못 쓰는 것도 데이터라고 알린다.
- 말이 끊기면 "지금 무슨 생각을 하세요"가 아니라 "계속 말씀해 주세요"로 잇는다. 유도하는 내용을 넣지 않는다.

소리 내어 생각하기는 부자연스럽고, 진행자의 질문이 행동을 바꿀 수 있다.<Ref n={6} />

| 하지 말 것 | 이유 | 대신 할 것 |
|---|---|---|
| 막힌 참가자에게 힌트를 준다 | 막힘이 핵심 데이터다 | 속으로 10까지 센 뒤 말할지 정한다<Ref n={7} /> |
| 참가자 질문에 답한다(여기 눌러도 되나요) | 설계가 가르쳐 주는 셈이다 | 되묻는다: 어떻게 하실 것 같으세요<Ref n={7} /> |
| 유도 질문을 한다(이 버튼 잘 보이죠) | 답이 질문에 들어 있다<Ref n={8} /> | 열린 질문: 이 화면에서 무엇이 눈에 띄셨나요 |
| 잘하고 있다고 칭찬한다 | 이후 행동이 진행자 반응에 맞춰진다 | 중립적으로 알겠습니다 정도만 말한다 |
| 참가자의 말을 해석해 요약한다 | 진행자의 생각이 섞인다 | 마지막 말을 억양만 올려 되풀이한다<Ref n={7} /> |

참가자가 질문하거나, 불분명한 말을 하거나, 자연스럽게 멈출 때만 말한다.<Ref n={7} /> 침묵이 잦은 개입보다 낫다.

## 지표를 고를 때

묻는 것에 맞춰 고른다. 5명짜리 결과에는 퍼센트를 쓰지 않는다. 5명 중 4명 성공처럼 적는다. 4에서 5명 테스트로는 좁은 신뢰구간을 얻기 어렵다.<Ref n={11} />

| 지표 | 재는 법 | 기준과 주의 |
|---|---|---|
| 과업 성공률 | 과업을 마친 비율 | 이유는 못 알려주는 거친 지표다.<Ref n={11} /> 참고 평균은 78%이며 49% 미만이면 하위 4분위다.<Ref n={12} /> 목표값이 아니라 출발점이다 |
| 성공 수준 | 완전, 사소한 문제 있음, 큰 문제 있음, 실패 | 각각 따로 보고한다. 숫자를 매겨 평균 내지 않는다.<Ref n={11} /> |
| 소요 시간 | 과업 시작에서 끝까지 | 소리 내어 생각하면 달라질 수 있다(확인 필요) |
| 오류 수 | 잘못 누름, 되돌아감 | 무엇을 오류로 셀지 사전에 정한다. 복구 가능 여부도 나눈다 |
| 과업별 만족 | 과업 직후 한 문항, 7점 | 어느 과업이 힘들었는지 가려낸다.<Ref n={14} /> |
| SUS | 10문항 5점 설문 | 아래 표 |

SUS는 홀수 문항은 응답에서 1을 빼고, 짝수 문항은 5에서 응답을 뺀 뒤, 합계에 2.5를 곱해 0에서 100점으로 만든다.<Ref n={13} />

| SUS 점수 | 해석 |
|---|---|
| 68 | 약 500개 연구의 평균이며 50번째 백분위<Ref n={13} /> |
| 74 | 70번째 백분위<Ref n={13} /> |
| 80 이상 | 상위 약 10% 수준<Ref n={14} /> |

## A/B 테스트를 돌릴 때

A/B 테스트는 어느 쪽 수치가 높은지만 알려 준다. 이유는 정성 데이터로 확인한다.

1. 가설과 판정할 지표 하나를 정한다.
2. 감지하고 싶은 최소 차이를 정한다.
3. 필요한 표본 크기를 시작 전에 계산한다.
4. 무작위로 배정하고 계획한 표본이 찰 때까지 둔다.
5. 끝난 뒤 한 번 판정한다.

| 규칙 | 이유 |
|---|---|
| 표본 크기를 사전에 정한다 | 사전에 정해야 유의성 판정이 유효하다<Ref n={17} /> |
| 중간에 결과를 보고 멈추지 않는다 | 확인할 때마다 우연히 유의하게 보일 기회가 늘어 오탐이 급증한다<Ref n={17} /> |
| 한 번에 하나만 바꾼다 | 둘 이상 바꾸면 무엇이 효과였는지 알 수 없다(일반론) |
| 정성 데이터와 같이 본다 | 수치는 이유를 알려주지 않는다 |
| 유의하지 않아도 차이 없음이라고 쓰지 않는다 | 표본이 모자라 못 찾았을 수 있다(일반론) |

최악 사례로 한 시뮬레이션에서는 실제 효과가 없는데도 매번 확인하며 멈추면 의도한 5%가 26.1%까지 올라갔다.<Ref n={17} /> 중간 확인이 꼭 필요하면 확인 시점을 미리 정하는 설계를 쓴다.

## 정성과 정량을 같이 볼 때

| 묻는 것 | 정량 | 정성 |
|---|---|---|
| 어디서 막히나 | 단계별 이탈률, 성공률 | 세션에서 멈춘 순간 |
| 왜 막히나 | 알 수 없다 | 소리 내어 생각하기, 후속 질문 |
| 얼마나 많은 사람이 겪나 | 로그, 설문 | 알 수 없다 |
| 고친 뒤 나아졌나 | 같은 지표의 전후 비교 | 같은 과업을 다시 관찰 |

- 정량이 이상 지점을 가리키면 정성으로 원인을 찾고, 고치고, 정량으로 다시 확인한다.
- 한 명의 특이한 반응은 가설로만 둔다. 반복되는 패턴만 이슈로 올린다.
- 참가자의 해결책을 그대로 반영하지 않는다. 관찰한 문제를 설계 가설로 바꾼다.

## 증상으로 찾기

| 증상 | 원인 | 처방 |
|---|---|---|
| 참가자가 과업 문구의 단어를 곧바로 찾는다 | 과업에 UI 용어가 들어갔다 | 메뉴, 버튼 이름을 문구에서 뺀다 |
| 참가자가 말이 없다 | 안내가 부족하거나 진행자가 자주 끊는다 | 시작 안내를 다시 하고 침묵 규칙을 지킨다 |
| 5명이 다 성공했는데 출시 후 이탈한다 | 과업이 실제 목표와 다르거나 모집이 편향됐다 | 과업의 현실성과 참가자 조건을 점검한다 |
| 세션마다 문제가 제각각이다 | 사용자군이 섞였거나 과업이 열려 있다 | 사용자군을 나눈다 |
| SUS는 높은데 과업 실패가 많다 | SUS는 인식이라 성과와 상관이 약하다 | 행동 지표를 함께 본다 |
| A/B가 처음엔 유의하다가 사라진다 | 중간 확인으로 인한 오탐 | 사전 표본 크기와 종료 시점을 지킨다 |
| 내 기기에서는 빠른데 지표가 나쁘다 | 판정은 75번째 백분위다 | 현장 데이터를 모바일 기준으로 본다 |
| 고쳤는데 지표가 안 움직인다 | 가설이나 문제 정의가 틀렸다 | 위 순환표의 돌아갈 곳으로 간다 |

## 점검 체크리스트

- 알고 싶은 질문이 2에서 3개로 적혀 있고 가설과 연결된다.
- 과업에 메뉴 이름, 버튼 이름, 단계 지시가 없다.
- 참가자 조건이 사용자군별로 나뉘어 있다.
- 질적이면 사용자군당 5명 단위로 반복하고, 수치를 내면 20명 이상이다.
- 파일럿을 최소 1명 돌렸다.
- 진행자가 힌트, 유도 질문, 칭찬을 하지 않았다.
- 성공 수준을 나눠 적었고, 5명 결과에 퍼센트를 쓰지 않았다.
- 관찰과 해석이 나뉘어 있고, 심각도(0에서 4)와 빈도(몇 명 중 몇 명)가 있다.
- 서명 동의서와 녹화 고지를 받았다.
- A/B는 표본 크기를 사전에 정했고 중간에 멈추지 않았다.
- 재측정은 같은 과업, 같은 지표, 새 참가자다.
