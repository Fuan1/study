## 사용자가 훑어볼 때

사용자는 읽지 않고 훑는다. 처음 괜찮아 보이는 선택지를 고르고, 사용법은 읽지 않은 채 짐작으로 쓴다.<Ref n={1} /> 설명문으로 고치려 하지 말고 화면을 바꾼다.

| 사용자 행동 | 규칙 |
|---|---|
| 훑는다 | 제목과 라벨에 핵심을 압축한다. 소제목, 굵은 핵심어, 짧은 문단, 목록을 쓴다 |
| 처음 괜찮은 것을 고른다 | 올바른 선택지를 처음 눈에 닿는 곳에 둔다 |
| 사용법을 읽지 않는다 | 설명 없이도 목적이 드러나게 한다 |

| 나쁜 예 | 고친 예 | 이유 |
|---|---|---|
| 결론이 세 번째 문단에 있다 | 제목과 첫 줄에 결론과 행동을 쓴다 | 훑는 사람은 앞부분만 본다 |
| 긴 문단 하나 | 소제목 + 짧은 문단 + 목록 | 훑는 경로를 서식으로 만든다 |
| 한 화면에 같은 비중의 버튼 세 개 | 주 행동 하나만 강조한다 | 한 화면 한 목적 |
| 안내문으로 주의를 준다 | 실수가 안 나는 화면으로 바꾼다 | 안내문은 읽히지 않는다 |

## 중요한 정보를 놓을 때

핵심은 글의 앞, 줄의 앞, 왼쪽 가장자리에 둔다. 서식 없는 긴 글에서는 첫 줄들과 줄 앞쪽 단어가 더 많이 주목받는다.<Ref n={4} /><Ref n={5} />

<Figure caption="서식 없는 긴 글에서 시선이 많이 가는 곳은 첫 줄, 짧은 두 번째 가로, 왼쪽 가장자리다. 실제 시선 데이터가 아니라 단순화한 도식이다.">
  <FPattern />
</Figure>

| 규칙 | 이유와 한계 |
|---|---|
| 결론과 핵심 단어는 줄 앞에 쓴다 | 줄 앞쪽 단어가 뒤쪽보다 더 주목받는다<Ref n={5} /> |
| 소제목, 굵은 핵심어, 목록을 쓴다 | 서식이 있고 제목 위주로 보면 F자가 아니라 층층이 쌓인 형태가 된다<Ref n={5} /> |
| 가격과 숫자는 찾기 쉬운 자리에 따로 둔다 | 숫자를 찾을 때는 다른 방식으로 본다<Ref n={4} /> |
| 내비게이션에는 이 규칙을 적용하지 않는다 | 내용 영역에 대한 관찰이다<Ref n={4} /> |

<Callout kind="warn">
F자형은 서식 없는 글에서 나타나는 결과다. 완벽한 F는 드물다. 레이아웃을 F자에 맞춰 짜는 규칙이 아니라, 오른쪽과 아래의 중요한 내용이 놓친다는 경고로 쓴다. 2017년 NN/g는 데스크톱과 모바일 모두에서 나타난다고 재확인했다.<Ref n={5} />

## 눈에 띄어야 하는 요소를 만들 때

크고 화려하다고 보이는 것이 아니다. 광고처럼 보이는 요소는 광고가 아니어도 무시된다.<Ref n={7} /> 중요한 공지, 가입 유도, 쿠폰 배너에 광고의 문법을 쓰지 않는다.

| 광고로 읽히는 조건 | 하지 마라 | 고쳐라 |
|---|---|---|
| 위치 | 상단 띠, 오른쪽 열에 둔다 | 본문 흐름 안에 둔다 |
| 시각 처리 | 움직임, 색 배경, 화려한 서식을 쓴다 | 본문과 같은 서식 언어를 쓴다 |
| 근접 오염 | 진짜 콘텐츠를 광고 옆에 둔다 | 광고 슬롯에서 떨어뜨린다. 옆의 콘텐츠도 같이 무시된다 |
| 회피 | 광고를 본 영역 전체가 외면된다 | 중요한 요소를 그 영역에 두지 않는다 |

## 외워야 하는 것이 많을 때

사용자가 정보를 기억하지 않아도 과제를 끝내게 한다. 한 번에 다루는 묶음은 3에서 5개 안팎이다. 이 값은 의미 있는 청크 수이며 젊은 성인 기준이다.<Ref n={8} /> 비교표, 장바구니, 저장된 선택 같은 외부 기억 장치가 대응 수단이다.<Ref n={9} />

| 나쁜 예 | 고친 예 | 이유 |
|---|---|---|
| 전화번호 01012345678 | 010-1234-5678 | 낱개 11개가 묶음 3개가 된다 |
| 카드번호 16자리를 붙여 쓴다 | 4자리씩 끊어 보여 준다 | 16개가 묶음 4개가 된다 |
| 앞 단계 값을 뒤 단계에서 묻기만 한다 | 입력한 값을 뒤 단계에서 다시 보여 준다 | 기억을 화면이 맡는다 |
| 이전 화면의 값을 보며 비교하게 한다 | 항목을 나란히 놓는다 | 머릿속에 들고 있지 않게 한다 |

<Figure caption="용량의 단위는 글자 수가 아니라 청크다. 같은 11자리도 3, 4, 4로 묶으면 묶음 3개다. 가상의 번호를 쓴 가정 예시다.">

</Figure>

<Callout kind="warn">
3에서 5도, 흔히 인용되는 7도 메뉴나 목록의 항목 수 상한으로 쓰지 않는다.<Ref n={10} /> 값은 사람과 나이에 따라 다르고 정확한 값에는 학계 논쟁이 있다(확인 필요). 항목 수보다 묶는 방식과 외부 기억 장치를 본다.

## 화면이 복잡하다고 느껴질 때

과제 자체의 복잡도는 없앨 수 없지만 화면이 얹은 불필요한 처리는 줄일 수 있다. 과제가 복잡하면 줄이는 대신 단계를 나눈다. 아래를 확인한다.<Ref n={11} />

- 이해에 도움이 안 되는 장식, 배경, 움직임을 뺐다.
- 같은 정보를 한 화면에서 두 번 이상 보여 주지 않는다.
- 없어도 되는 문구(반복 안내, 인사말, 설명문)를 뺐다.
- 필수가 아닌 단계와 입력 항목을 뺐다.
- 익숙한 라벨과 배치를 써서 사용자가 이미 가진 사고틀을 이용한다.
- 앞에서 입력한 정보와 선택은 화면이 다시 보여 준다.
- 복잡한 과제는 단계로 나누고, 한 단계에는 판단 하나만 둔다.

## 기본값을 정할 때

기본값은 선택을 크게 움직인다. 그래서 기본값은 사용자에게 이익이 되는 쪽으로 정하고 변경 경로를 보여 준다.

| 나쁜 예(가정) | 고친 예 | 이유 |
|---|---|---|
| 마케팅 수신이 미리 체크되어 있다 | 필수 알림만 켜고 마케팅은 꺼 둔다 | 사용자가 손대지 않으면 기본값이 결과가 된다 |
| 유료 부가 상품이 미리 선택되어 있다 | 선택 해제 상태로 두고 이점을 설명한다 | 이익이 사용자 쪽에 있지 않다 |
| 기본값만 있고 바꾸는 곳이 안 보인다 | 기본값 옆에 변경 경로를 둔다 | 다른 선택을 할 수 있어야 한다 |

근거 한 줄. 장기 기증 등록이 기본값이 아닌 나라는 효과적 동의율이 4.25에서 27.5퍼센트였고, 기본값이 기증인 나라는 85.9에서 99.98퍼센트였다.<Ref n={12} />

<Figure caption="제도의 기본값만 달라도 등록 비율이 극단적으로 갈린다. 이웃한 독일과 오스트리아가 대표적이다. 값은 효과적 동의율이며 실제 기증 건수가 아니다.">
  <DefaultEffect />
</Figure>

<Callout kind="warn">
등록된 동의와 실제 행동은 다르다. 같은 논문에서 100만 명당 실제 기증자 수는 기본값이 기증인 쪽이 16.3퍼센트 높았다(14.1명에서 16.4명).<Ref n={12} /> 효과는 있지만 동의율의 격차만큼 크지는 않다.
</Callout>

## 가격과 할인을 표시할 때

처음 본 숫자가 이후 판단을 끌어당긴다. 룰렛 숫자 10을 본 집단의 추정 중앙값은 25퍼센트, 65를 본 집단은 45퍼센트였고, 정확도에 보상을 걸어도 효과는 줄지 않았다.<Ref n={13} /> 사용자가 숫자의 출처를 따져 보리라고 기대하지 않는다.

| 나쁜 예 | 고친 예 | 이유 |
|---|---|---|
| 팔린 적 없는 높은 정가 옆에 할인가를 둔다 | 실제로 판매한 가격만 기준가로 보여 준다 | 처음 본 숫자가 판단을 정한다 |
| 가장 비싼 숫자를 먼저 크게 보여 준다 | 사용자가 비교할 기준을 정직하게 보여 준다 | 무관한 숫자도 판단을 끌어당긴다 |
| 나가려는 사용자에게 사라진다는 문구를 반복한다 | 실제로 사라지는 것만 한 번 알린다 | 압박은 신뢰를 잃게 한다 |

<Callout kind="warn">
손실 문구가 이득 문구보다 더 잘 먹힌다고 가정하지 않는다. 손실이 이득보다 평균적으로 더 크게 작용한다는 증거가 충분하지 않다는 리뷰가 있다.<Ref n={14} /> 손실이 이득의 두 배 아프다는 식의 계수는 쓰지 않는다. 문구는 직접 시험해 정한다.
</Callout>

## 증상으로 찾기

| 증상 | 인지 원인 | 처방 |
|---|---|---|
| 눌러야 할 큰 버튼을 못 찾는다 | 광고 자리나 광고 모양이라 걸러진다 | 위치와 모양을 본문의 문법에 맞춘다 |
| 안내문을 읽지 않고 실수한다 | 훑기, 처음 괜찮은 것 선택 | 핵심을 앞에 두고 문장을 줄인다. 필요하면 화면 자체를 바꾼다 |
| 오른쪽이나 아래의 내용을 놓친다 | 서식 없는 글의 읽기 경향 | 핵심을 왼쪽과 줄 앞에 두고 서식을 준다 |
| 입력 도중 이탈하거나 오류가 많다 | 기억 부담, 불필요한 처리 | 단계를 나누고 이전 값을 다시 보여 준다 |
| 첫 화면에서 바로 나간다 | 10초 안에 가치가 안 보인다 | 가치 제안과 행동을 첫 화면에 쓴다 |
| 선택지가 많아 결정을 미룬다 | 기억과 처리 부담 | 묶기와 순서를 정리한다 |
| 설명서를 안 읽고 엉뚱하게 쓴다 | 짐작으로 헤쳐 나간다 | 신호와 동작을 일치시킨다 |
| 옵션이 기본값 그대로 남는다 | 기본값 효과 | 기본값을 사용자 이익에 맞추고 변경 경로를 보여 준다 |
| 가격 판단이 처음 본 숫자에 쏠린다 | 앵커링 | 비교 기준을 정직하게 보여 준다 |
