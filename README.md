# Study

분야별 학습 정리 레포. 학습 글은 React + Vite 뷰어로 읽는다.

| 폴더 | 분야 |
|---|---|
| 01-ux | UX / UI 리서치·디자인 |
| 02-data-analysis | 데이터 분석 실무 (문제 정의, SQL, 통계, 시각화, 보고) |
| 03-business-marketing | 비즈니스·마케팅 실무 (시장·고객, 가격·단위 경제성, 채널·광고, 측정, 법규) |

각 분야 폴더 구성: `course.json`(글 목록), `lessons/`(글 MDX), `notes/`(정리 노트), `resources/`(자료·링크), `practice/`(실습·예제). 노트 양식은 `_templates/note.md`, 글 양식은 `_templates/lesson.mdx`.

## 실행

```sh
npm install
npm run dev        # 개발 서버
npm run build      # 타입 검사 + dist/ 빌드
npm run preview    # 빌드 결과 미리보기
```

## 뷰어

실무 규칙을 찾아 읽는 아티클 뷰어. 블랙 계열 고정, 모바일 우선이다.

- **상황·증상 검색**: 홈과 상단 돋보기(데스크톱은 `/` 키)에서 "로딩", "버튼 크기" 같은 말로 해당 섹션을 찾는다.
- **현재 위치 표시**: 읽는 동안 상단 바에 지금 섹션이 표시되고, 목차 서랍에는 현재 글의 섹션이 펼쳐진다.
- **핵심 규칙 태그**: 글 맨 위 규칙을 해라 / 하지 마라 / 기준값 태그로 구분해 보여 준다.
- 하단 이전/다음 바(← → 키), 글 안 접이식 목차, 3열 이상 표의 모바일 카드 표시, 그림·출처 각주를 제공한다.
- 해시 라우팅 + 상대 경로 빌드라 `dist/`를 GitHub Pages 같은 정적 호스팅에 그대로 올릴 수 있다.
- 분야 추가는 폴더 + `course.json`, 글 추가는 `lessons/<id>-slug/index.mdx` 파일만 만들면 자동 인식되고 검색 색인에도 들어간다.

세부 규칙은 `CLAUDE.md` 참고.
