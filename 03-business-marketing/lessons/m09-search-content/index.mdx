## 키워드를 고를 때

규칙: 의도 일치는 곱하는 관문이고 나머지는 가중 합이다. 가중치는 관행이며 사업에 맞게 바꾼다.

| 기준 | 보는 것 | 점수 |
|---|---|---|
| 의도 일치 | 내 페이지 유형이 의도와 맞는가 | 0 불일치, 1 부분, 2 일치 |
| 전환 가능성 | 검색자가 목표 행동에 가까운가 | 1에서 5 |
| 경쟁 정도 | 상위가 이미 강한 사이트로 찼는가 | 1에서 5. 계산에는 6에서 뺀 값 |
| 검색량 | 도구의 월 추정 검색량 | 단계 = 1 + log10 의 정수 부분, 1에서 5 |

식은 `점수 = (의도 ÷ 2) × (0.4 × 전환 + 0.3 × (6 - 경쟁) + 0.3 × 검색량 단계) ÷ 5 × 100`이고 python 으로 계산했다.

| 키워드 | 입력(의도·전환·경쟁·검색량) | 단계 | 점수 |
|---|---|---|---|
| A200 의자 후기 | 2·5·2·500 | 3 | 82.0 |
| 사무용 의자 추천 | 2·4·4·22,000 | 5 | 74.0 |
| 의자 허리 아플 때 | 2·2·2·6,000 | 4 | 64.0 |
| 사무용 의자 | 1·3·5·90,000 | 5 | 30.0 |
| 의자 만드는 법 | 0·1·1·8,000 | 4 | 0.0 |

<Figure caption="검색량이 가장 큰 키워드가 1순위가 아니다. 의도와 경쟁이 순서를 바꾸고, 의도가 0이면 0점이다.">

</Figure>

검색량은 도구의 추정치다. 구글 키워드 플래너는 월 검색 수를 추정치로 안내하고 검색량이 아주 적은 키워드는 조회나 예측이 안 될 수 있다고 한다.<Ref n={1} /> 도구마다 산출 방식이 달라 값이 다를 수 있다(확인 필요).

- 검색량은 단계로만 쓴다. 단계 경계는 도구 차이로 흔들린다. 9,500은 4단계, 10,500은 5단계다. 사무용 의자 추천이 9,500으로 조회되면 74.0점이 68.0점이 되고 순서는 그대로다.
- 점수 차 10점 이내는 동률로 보고 의도와 전환 가능성으로 정한다(관행). 이미 노출되는 쿼리는 Search Console 의 노출수를 실측으로 쓴다.

## 같은 내용의 페이지가 여러 개일 때

규칙: 같은 내용이 여러 URL(파라미터, 슬래시, http와 https, 필터)로 열리면 대표 URL 하나를 정한다. 지정하지 않으면 구글이 고른다.<Ref n={10} />

| 방법 | 신호 강도(공식 표현) | 쓸 때 |
|---|---|---|
| 301 리디렉션 | 가장 강하다 | 옛 URL 을 더 안 쓸 때, 통합·이전<Ref n={11} /> |
| rel canonical | 강하지만 힌트이지 명령이 아니다 | 여러 URL 이 계속 열려야 할 때 |
| 사이트맵 | 약하다 | 대표 URL 만 넣는다 |

- 대표 페이지에도 자기 자신을 가리키는 canonical 을 둔다. 방법 간에 대표가 충돌하지 않게 한다.
- canonical 대신 robots.txt 나 noindex 를 쓰지 않는다. 공식이 하지 말라는 방법이다.<Ref n={10} />

## 색인을 제어할 때

규칙: 크롤링(가져가기)과 색인(검색 결과 후보에 넣기)은 다른 일이고 도구도 다르다.

| 도구 | 하는 일 | 하지 못하는 일 |
|---|---|---|
| robots.txt | 크롤러 접근 관리 | 색인 제외가 아니다. 막아도 다른 곳의 링크로 URL 이 색인될 수 있다<Ref n={12} /> |
| noindex | 색인에서 제외 | robots.txt 로 막힌 페이지에서는 읽히지 않는다. 반영에 수개월 걸릴 수 있다<Ref n={13} /> |
| 사이트맵 | URL 목록을 알림 | 크롤링·색인 보장 없음<Ref n={14} /> 한 파일 50MB 또는 5만 URL, 대표 URL 만<Ref n={15} /> |
| 색인 요청 | 소수 URL 크롤링 요청 | 보장 없음, 며칠에서 몇 주, 반복해도 안 빨라진다<Ref n={16} /> |
| 404 또는 410 | 삭제한 URL 을 색인에서 뺀다 | 구글은 둘을 같게 다룬다. 없다는 화면을 200 으로 주면 soft 404<Ref n={17} /> |

<Figure caption="robots.txt 로 막으면 noindex 를 읽을 수 없다. 색인에서 빼려면 막지 말고 noindex 를 읽히게 둔다.">
  <IndexFlow />
</Figure>

- 임시·내부 페이지를 robots.txt 로만 막은 것은 색인 제외가 아니다. 노출되면 안 되면 비밀번호로 보호한다(공식 권고).<Ref n={12} />
- noindex 를 넣고 robots.txt 로도 막았다면 robots.txt 규칙부터 푼다.

## 성과를 측정할 때

규칙: 지표 정의부터 고정한다. Search Console 공식 정의의 요약이다.<Ref n={21} />

| 클릭수 | 구글에서 내 사이트로 이동한 클릭 | 돌아와 같은 링크를 다시 눌러도 1회 |

| 평균 게재순위 | 링크가 차지한 가장 위 순위를 쿼리 전체에 평균, 1이 맨 위 | 2위와 3위 두 쿼리면 2.5 |

| 쿼리 단위와 페이지 단위 | 쿼리 기준은 사이트 단위로 합쳐 같은 쿼리의 내 결과 둘이 노출 1건, 페이지 기준은 페이지별<Ref n={22} /> | 한 분석에 한 기준만 쓰고 합계를 맞추지 않는다 |

## 콘텐츠를 발행·갱신·통합·삭제할 때

규칙: 페이지마다 넷 중 하나로 정한다. 기간은 관행이고 조치의 동작은 공식 문서로 확인했다.

| 행동 | 판단 기준 | 하는 일 |
|---|---|---|
| 발행 | 의도 일치 2점이고 같은 의도의 기존 페이지가 없다 | 의도 하나로 쓰고 링크·사이트맵에 넣고 2주 뒤 색인 확인 |
| 갱신 | 노출은 유지되는데 클릭이 줄었거나 내용이 낡았다 | 제목·설명·수치 수정. lastmod 는 주요 변경일 때만<Ref n={15} /> |
| 통합 | 같은 의도의 페이지 둘이 같은 쿼리에 번갈아 나온다 | 더 나은 쪽에 합치고 나머지는 301<Ref n={11} /> |
| 삭제 | 사업과 무관하고 유입·링크·전환이 없고 합칠 곳이 없다 | 404 또는 410, 사이트맵·내부 링크에서 제거<Ref n={17} /> |

## 증상으로 찾기

색인 상태 이름은 Search Console 공식 보고서 기준이다.<Ref n={25} />

| 증상 | 원인 | 처방 |
|---|---|---|
| 색인 안 됨: 발견됨 - 현재 색인 안 됨 | URL 은 알지만 아직 크롤링 전<Ref n={25} /> | 내부 링크·사이트맵에 넣고 기다린다. 색인 요청은 한 번 |
| 색인 안 됨: 크롤링됨 - 현재 색인 안 됨 | 가져갔지만 색인하지 않았다 | 독창성·완결성을 점검하고 중복이면 통합 |
| 색인 안 됨: robots.txt 차단 또는 noindex | 규칙이나 태그가 막고 있다 | 의도한 것인지 확인. 색인 제외가 목적이면 robots.txt 를 풀고 noindex |
| 색인 안 됨: 중복·다른 canonical·soft 404 | 대표 URL 이 불명확하거나 없는 페이지를 200 으로 응답 | canonical·리디렉션 정리, 없는 페이지는 404 |
| 노출은 되는데 클릭이 낮다 | 노출 유지에 클릭만 줄면 제목 링크·스니펫 문제라고 구글이 안내<Ref n={24} />. 의도 불일치도 원인 | 상위 결과 제목과 비교해 고유한 제목·설명으로 바꾸고 28일 본다 |
| 클릭은 되는데 전환이 낮다 | 의도와 페이지 유형 불일치, 느린 로딩, 다음 행동 불명 | 페이지 유형을 맞추고 속도 기준 확인. 랜딩 구조는 m11 |

## 점검 체크리스트

- 페이지마다 검색 의도 하나와 맞는 페이지 유형이 정해져 있는가.
- 키워드 점수표에 네 기준이 있고 의도 0점을 제외했으며 검색량을 추정치 단계로 썼는가.
- 제목·설명이 페이지마다 다르고, 내부 링크가 a 요소와 href 이며, 이미지에 설명 alt 가 있는가.
- 대표 URL 과 자기 참조 canonical 이 있고 사이트맵에는 대표 URL 만 있는가.
- 색인에서 뺄 페이지는 robots.txt 로 막지 않고 noindex 를 읽히게 두었는가.
- LCP 2.5초, INP 200ms, CLS 0.1 이하를 75번째 백분위로 모바일·데스크톱 따로 확인했는가.
- 순위·알고리즘 단정이 없고, 네이버 규칙은 확인했거나 확인 필요로 표시했는가.
- 성과 판정이 같은 쿼리·페이지 집합, 7일의 배수 기간, 노출 수천 이상 묶음인가.
