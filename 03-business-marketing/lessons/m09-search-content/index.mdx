## 검색 의도를 가를 때

규칙: 키워드를 보기 전에 의도를 정한다. 구글 검색 품질 평가자 지침은 쿼리를 네 의도로 설명한다.<Ref n={3} />

| 의도 | 구글 설명(요약) | 맞는 페이지 형식(이 글의 매핑) |
|---|---|---|
| Know | 정보를 찾거나 주제를 알아본다 | 가이드·설명 글, 비교·목록 글 |
| Do | 구매·다운로드·이용 같은 목표를 이룬다 | 상품·가입·도구 페이지 |
| Website | 특정 사이트나 페이지를 찾는다 | 홈·브랜드 페이지 |
| Visit-in-person | 업체나 장소를 찾아간다 | 매장·위치 안내 페이지 |

- 지침 2025년 9월 11일판의 분류다. 평가용 문서이고 하나의 평가가 특정 페이지의 순위를 직접 바꾸지 않는다고 밝힌다.<Ref n={3} /> 형식 매핑은 이 글의 작업 기준이다.
- 지침은 Know 와 Do 의 경계가 흐리고, 한 쿼리에 의도가 여럿일 수 있고, 쿼리의 지배적 의미가 시간에 따라 바뀐다고 한다.<Ref n={3} /> 그러니 상위 결과의 페이지 형식을 직접 보고 정한다(관행).
- 쿼리 목록은 이미 노출되는 쿼리로 시작한다. 구글은 Search Console 성능 보고서의 쿼리 표,<Ref n={4} /> 네이버는 노출 및 클릭 리포트의 키워드 상위 30건이다.<Ref n={5} />

## 콘텐츠를 쓸 때

## 같은 내용의 페이지가 여럿이거나 색인에서 뺄 때

규칙: 대표 URL 하나를 정한다. 지정하지 않으면 구글이 고른다.<Ref n={16} />

| 방법 | 공식 표현 | 쓸 때 |
|---|---|---|
| 리디렉션 | 강한 신호 | 옛 URL 을 더 안 쓸 때 |
| rel canonical | 강한 신호 | 여러 URL 이 계속 열려야 할 때 |
| 사이트맵 | 약한 신호 | 대표 URL 만 넣는다 |

- 대표 페이지에도 자기 참조 canonical 을 둔다. canonical 대신 robots.txt 나 noindex 를 쓰지 않는다.<Ref n={16} />

크롤링(가져가기)과 색인(검색 결과 후보에 넣기)은 다른 일이고 도구도 다르다.

| 도구 | 하는 일 | 한계 |
|---|---|---|
| robots.txt | 크롤러 접근 관리 | 색인 제외 수단이 아니다. 다른 곳의 링크로 설명 없이 색인될 수 있다<Ref n={17} /> |
| noindex | 색인에서 제외 | robots.txt 로 막힌 페이지에서는 읽히지 않는다. 반영에 몇 달 걸릴 수 있다<Ref n={18} /> |
| 사이트맵 | URL 알림 | 색인 보장 없음. 500쪽 미만에 링크가 잘 연결되면 덜 필요하다<Ref n={19} /> |
| 색인 요청 | 소수 URL 크롤링 요청 | 며칠에서 몇 주. 같은 URL 을 반복해도 안 빨라진다<Ref n={20} /> |
| 404·410 | 삭제한 URL 처리 | 구글은 같게 다룬다. 없다는 화면을 200 으로 주면 soft 404<Ref n={21} /> |

## 네이버에서도 노출해야 할 때

규칙: 네이버 규칙은 서치어드바이저 웹마스터 가이드로 정한다. 아래는 직접 읽은 내용이고 화면·메뉴는 바뀔 수 있어 확인 필요.

| 항목 | 가이드가 말하는 것 |
|---|---|
| 사이트 등록 | 웹마스터도구에 호스트 단위로 등록·소유확인. 경로 단위는 안 된다<Ref n={22} /> |
| 로봇 | 이름은 Yeti. robots.txt·방화벽에서 허용. robots.txt 는 text/plain 으로 응답한다<Ref n={23} /> |
| 제목·설명 | 페이지마다 고유하게. 같은 키워드 2회 이상 반복은 불이익 가능<Ref n={24} /> |
| 중복 | 같은 내용의 여러 호스트·URL 을 만들지 않는다. 필요하면 대표 주소로 301<Ref n={25} /> |
| 링크 | a 요소의 href. 자바스크립트 함수만 쓴 링크, 해시 뒤 주소는 해석하지 않는다<Ref n={26} /> |
| 반영 | 로봇 방문 뒤 최대 1주일 이내. 안 나오면 noindex·nofollow 를 확인<Ref n={22} /> |
| 오류 응답 | 없음 404, 로그인 필요 403, 이전 301, 점검 503. 오류 화면을 200 으로 주지 않는다<Ref n={27} /> |

네이버 노출·클릭 리포트는 웹 검색 영역만 산정하고 기준일이 1주 전이라 Search Console 과 숫자를 더하지 않는다.<Ref n={5} />

## 속도와 모바일을 점검할 때

규칙: 실제 방문의 75번째 백분위로 모바일과 데스크톱을 나눠 판정한다.<Ref n={28} />

| 지표 | 보는 것 | good 기준 |
|---|---|---|
| LCP | 주요 콘텐츠 표시 시간 | 2.5초 이하 |
| INP | 입력에 반응하는 시간 | 200ms 이하 |
| CLS | 예상 못한 레이아웃 이동 | 0.1 이하 |

구글은 이 지표가 핵심 순위 시스템이 보상하려는 것과 맞닿아 있다고 하지만 순위를 보장한다고는 하지 않는다.<Ref n={29} /> 개선 방법은 UX 과정 u10 과 m11 에 있다.

규칙: 페이지마다 발행, 갱신, 통합, 삭제 중 하나로 정한다. 기준은 이 글의 작업 기준이고 동작은 공식 문서로 확인했다.

| 클릭수·CTR | 같음 | 노출이 그대로인데 줄면 제목·설명 문제 | 제목·설명 수정 |
| 평균 순위 | 같음 | 단독 판정 금지, 쿼리 구성 확인 | 쿼리별로 본다 |
| 방문·전환 | 분석 도구 | Search Console 클릭과 숫자가 다르다<Ref n={32} /> | 클릭 뒤 구조는 m11 |

## 효과가 늦게 나타날 때

규칙: 판정 시점을 발행·변경 전에 정해 두고, 그 전에는 결론 내지 않는다.

- 구글은 어떤 변경은 몇 시간, 어떤 변경은 몇 달 걸리니 몇 주 기다린 뒤 효과를 보라고 안내한다.<Ref n={30} /> 콘텐츠가 도움이 된다고 시스템이 장기적으로 판단하기까지 몇 달이 걸릴 수 있다고도 한다.<Ref n={33} />
- 색인은 며칠에서 몇 주,<Ref n={20} /> noindex 반영은 몇 달까지 걸린다.<Ref n={18} />
- 검색 유입이 매출에 기여한 몫과 증분 효과는 Search Console 로 가릴 수 없다. 분석 도구와는 URL 범위, 중복 제거, 봇 제외, 시간대 때문에 숫자가 다르다.<Ref n={32} /> 기여·증분은 m12 에서 다룬다.

## 증상으로 찾기

| 증상 | 원인 | 처방 |
|---|---|---|
| 검색에 안 나온다 | 크롤러 차단, 200 아님, noindex, 색인 전<Ref n={1} /> | 세 요건과 noindex 확인, 색인 요청은 한 번 |
| 노출은 그대로, 클릭만 감소 | 제목 링크·스니펫이 약하거나 경쟁 결과가 눈에 띔<Ref n={33} /> | 고유한 제목·설명으로 고치고 기간을 둔다 |
| 노출과 클릭이 같이 감소 | 알고리즘 변경, 기술·보안 문제, 스팸, 계절성<Ref n={33} /> | 기술 점검, 수동 조치 확인, 전년 같은 기간 비교 |
| 평균 순위만 나빠짐 | 쿼리 구성이 바뀜(신규 롱테일 쿼리) | 같은 쿼리 집합으로 다시 비교 |
| 네이버에서만 안 나옴 | Yeti 차단, noindex, 반영 대기<Ref n={22} /> | 로봇 허용과 noindex 확인, 1주 기다림 |

## 흔한 실수

| 나쁜 예 | 고친 예 | 이유 |
|---|---|---|
| robots.txt 로 색인을 뺀다 | noindex 를 읽히게 둔다 | 막으면 읽히지 않는다 |
| 평균 순위 한 숫자로 보고한다 | 노출·클릭과 쿼리별로 본다 | 구성이 바뀌면 평균이 흔들린다 |
| 의도가 다른 쿼리를 한 페이지에 몰아 쓴다 | 의도별로 페이지를 나눈다 | 의도마다 맞는 형식이 다르다 |

## 점검 체크리스트

- 페이지마다 검색 의도 하나와 맞는 형식이 기획표에 있는가.
- 제목·설명이 고유하고, 내부 링크가 a 요소와 href 이며, 이미지에 설명 alt 가 있는가.
- 대표 URL 과 자기 참조 canonical 이 있고, 사이트맵에는 대표 URL 만 있는가.
- 색인에서 뺄 페이지는 robots.txt 로 막지 않고 noindex 를 읽히게 두었는가.
- LCP 2.5초, INP 200ms, CLS 0.1 이하를 75번째 백분위로 모바일·데스크톱 따로 확인했는가.
- 순위 약속이 없고, 대량 생성·키워드 채우기가 없는가.
- 네이버는 Yeti 허용과 응답 코드, 리포트를 따로 확인했는가.
- 성과 판정이 같은 쿼리·페이지 집합, 같은 길이의 기간, 정한 시점인가.
