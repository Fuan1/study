## 설문을 만들기 전에

규칙: 아래 표를 한 줄씩 채운 뒤에 문항을 쓴다. 못 채우면 설문이 아니라 정리가 먼저다.

| 정할 것 | 쓰는 방식 | 나쁜 예 → 고친 예 |
|---|---|---|
| 결정 | 어떤 선택지 중 무엇을 고르는가 | 고객이 뭘 원하는지 알고 싶다 → 요금제 A안과 B안 중 어느 쪽을 낼지 정한다 |
| 결정을 바꿀 답 | 답 구간마다 다른 행동을 적는다 | 만족도 조사 → 불만 비율이 20%를 넘으면 환불 정책을 바꾼다(기준은 가정) |
| 대상 집단 | 명단이나 조건으로 말한다 | 우리 고객 → 최근 6개월 안에 한 번 이상 구매한 회원 |

| 보고 표 | 결과 표의 빈 틀을 먼저 그린다 | 나중에 정함 → 표의 행과 열이 문항과 보기를 정한다 |

- 행동이 궁금하면 설문보다 로그가 먼저다. 말한 의향은 실제 행동과 어긋날 수 있다.

## 문항을 쓸 때

규칙: 한 문항은 한 가지를 묻고, 응답자가 같은 뜻으로 읽게 쓴다. 문항을 바꾸면 결과가 달라진다. 미국 설문 사례에서 같은 내용을 다른 낱말로 물었더니 찬성이 51%와 44%로 갈렸다.<Ref n={1} />

| 문제 | 나쁜 문항 | 고친 문항 |
|---|---|---|
| 유도 | 빠르고 편리해진 새 결제, 만족하셨나요? | 새 결제 방식에 얼마나 만족하셨나요? (매우 불만족에서 매우 만족) |
| 두 가지 묻기 | 배송과 포장에 만족하셨나요? | 배송 만족도, 포장 만족도를 각각 묻는다<Ref n={1} /> |
| 모호한 기간 | 자주 구매하세요? | 최근 3개월 동안 몇 번 구매하셨나요? (0회 / 1-2회 / 3-5회 / 6회 이상) |
| 보기 겹침 | 20-30세 / 30-40세 | 20-29세 / 30-39세 / 40-49세 |
| 보기 누락 | 구매 이유: 가격 / 디자인 | 가격 / 디자인 / 기타(직접 입력) / 해당 없음 |
| 척도 방향 | 1번 문항 5=만족, 2번 문항 5=불만 | 모든 문항에서 큰 숫자가 같은 쪽 |
| 필수 응답 | 모든 문항 필수 | 결정에 쓰는 문항만 필수. 모름과 응답 안 함 보기를 둔다 |
| 민감 질문 위치 | 첫 화면에서 소득을 묻는다 | 뒤쪽에 두고 구간 보기와 응답 안 함 보기를 준다<Ref n={1} /> |

## 설문의 순서와 길이를 정할 때

규칙: 쉬운 문항부터, 일반에서 구체로, 민감한 문항과 인구통계는 뒤에 둔다.<Ref n={1} />

- 앞 문항은 뒤 문항의 맥락이 된다. 같은 주제는 모아 두고, 일반 문항을 구체 문항보다 먼저 묻는다. 순서만 바꿔도 지지율이 37%에서 45%로 바뀐 사례가 있다.<Ref n={1} />
- 길이는 일반 원칙으로 정한다. 문항마다 "이 답이 바꿀 결정"을 적고 못 적으면 뺀다. 길어질수록 중도 이탈과 대충 고른 응답이 늘어난다. 문항 수의 기준값은 쓰지 않는다. 대신 시험 응답으로 걸리는 시간을 직접 잰다.
- 본 발송 전에 5명에서 10명에게 소리 내어 풀게 한다. 문항을 다르게 읽는 곳, 보기에 없는 답, 막히는 곳을 찾는다(u08).

## 표본 크기를 정할 때

규칙: 오차 범위와 신뢰수준을 먼저 정하고 필요한 응답 수를 계산한다. 비율 추정이며 단순 무작위 표본을 가정한다.

| 기호 | 뜻 | 값 |
|---|---|---|
| e | 허용 오차(비율) | 0.05는 ±5%p |
| z | 신뢰수준의 z 값 | 95%는 1.96 |
| p | 예상 비율 | 모르면 0.5(분산 최대) |
| N | 모집단 크기 | 알 때만 보정에 쓴다 |

- 기본 식: `n0 = z²·p(1-p)/e²`
- 유한 모집단 보정: `n = n0 / (1 + (n0-1)/N)`.<Ref n={2} /> 올림 전 값으로 계산하고 마지막에 올린다. 표본이 모집단의 5%를 넘으면 효과가 눈에 띈다(관행).

```python
from statistics import NormalDist
import math

z = NormalDist().inv_cdf(0.975)

def n0(e, p=0.5):
    return z**2 * p * (1 - p) / e**2

def fpc(n, N):
    return n / (1 + (n - 1) / N)

print(math.ceil(n0(0.05)))
print(math.ceil(fpc(n0(0.05), 1000)))
```

| 모집단 N | ±10% | ±5% | ±3% |
|---|---|---|---|
| 아주 큼 | 97 | 385 | 1,068 |
| 10,000 | 96 | 370 | 965 |
| 5,000 | 95 | 357 | 880 |
| 1,000 | 88 | 278 | 517 |
| 500 | 81 | 218 | 341 |

<Figure caption="오차를 절반으로 줄이면 필요한 응답은 약 4배다. p=0.5, 95%, 모집단이 아주 클 때이다.">
  <MoeCurve />
</Figure>

- 모집단이 작으면 보정으로 표본이 준다. 모집단이 1만이어도 ±5%는 385명에서 370명으로 줄 뿐이다. 모집단이 크면 표본 크기가 오차를 정한다.
- p를 알면 줄어든다. p=0.2이면 ±5%는 246명, ±3%는 683명이다. 극단적인 비율이 확실할 때만 쓰고, 모르면 0.5를 쓴다.
- 신뢰수준을 올리면 늘어난다. ±5%에서 90%는 271명, 95%는 385명, 99%는 664명이다.
- n은 보낸 수가 아니라 유효 응답 수다. 응답률 20%를 가정하면 385명을 받으려면 1,925명에게 보내야 한다.
- 이 오차는 표본 추출 오차만 담는다. 무응답, 문항 오해, 모집 편향은 들어 있지 않다.

### 비확률 표본일 때

규칙: 패널, SNS 링크, 앱 팝업 같은 자발적 참여 응답에는 표본 오차 범위를 계산해 붙이지 않는다. 오차 범위는 모든 대상이 알려진 확률로 뽑힌 표본에서만 성립한다.<Ref n={3} />

| 표본 | 오차 범위 | 보고 방법 |
|---|---|---|
| 고객 명단에서 무작위 추출해 발송 | 명단 안의 고객에 대해 계산한다 | 응답률을 같이 쓰고 무응답은 별도 점검 |
| 패널, SNS 링크, 팝업 | 계산할 근거가 없다 | n만 쓰고 "오차 범위 산출 불가"로 적는다 |

비확률 표본의 결과는 모집단 수치가 아니라 응답한 사람들의 경향으로 쓴다. 모델로 구간을 만들었다면 가정을 적고 표본 오차와 구분한다.<Ref n={3} />

## 응답이 한쪽으로 치우쳐 보일 때

규칙: 응답이 이상하면 문항, 표본, 응답 환경 순으로 의심한다. 편향은 오차 범위로 줄지 않으므로 표본을 늘려도 사라지지 않는다.

| 증상 | 원인 | 처방 |
|---|---|---|
| 응답자 구성이 고객 DB와 다르다(연령, 플랜) | 표본 선택 편향: 모집 경로에 닿는 사람만 응답 | 모집 경로 추가, DB 구성과 대조, 비교 결과를 보고서에 적는다 |
| 만족도가 지나치게 높다 | 무응답 편향: 열성 고객이 주로 응답 | 응답자와 미응답자를 DB 속성으로 비교, 독촉 후 응답한 사람과 먼저 응답한 사람의 차이를 본다(관행) |
| 부끄러운 행동(과소비, 미납)이 실제보다 적다 | 사회적 바람직성: 좋게 보이려는 답 | 자기 기입식(응답자가 직접 입력)과 익명으로 받고 비난 없는 문장으로 쓴다<Ref n={1} /> |
| 첫 보기가 계속 많이 뽑힌다 | 순서 효과<Ref n={1} /> | 보기 순서를 무작위로 섞고, 문항 순서 두 가지로 나눠 비교한다 |
| 모두 같은 번호만 찍는다 | 응답 피로 | 문항 수를 줄이고 이탈 구간을 확인한다. 같은 번호만 찍은 응답은 따로 세어 둔다(관행) |

## 가중치를 줄 때

규칙: 가중치는 응답자 구성을 알려진 모집단 구성에 맞추는 보정이다. 효과가 있을 때만 쓰고, 쓰면 오차 범위가 커진다는 비용을 같이 보고한다.

- 줄 때: 응답자와 모집단의 구성이 알려진 변수(연령, 성별, 플랜)에서 다르고, 그 변수가 결과와 관련 있고, 모집단 비율의 공식 값이 있을 때.
- 가중치는 변동을 키워 오차 범위를 넓힌다(설계 효과).<Ref n={4} />
- 주지 마라: 모집단 비율을 모를 때, 변수가 결과와 무관할 때, 칸에 응답이 거의 없을 때(큰 가중치 하나가 결과를 흔든다), 비확률 표본의 편향을 가중치로 없애려 할 때. 인구통계 가중치는 편향을 조금만 줄이고 때로는 악화시켰다는 연구가 있다.<Ref n={5} />

식: 가중치 `w = 모집단 비율 / 표본 비율`, 유효 표본 `n_eff = (Σw)² / Σw²`, 설계 효과 `n / n_eff`.<Ref n={6} />

가상 예: 응답 500명, 모집단 구성은 공식 통계라고 가정한다.

| 연령대 | 표본 비율 | 모집단 비율 | 가중치 |
|---|---|---|---|
| 20-30대 | 60% | 35% | 0.58 |
| 40-50대 | 30% | 40% | 1.33 |
| 60대 이상 | 10% | 25% | 2.50 |

`n_eff`는 367명, 설계 효과 1.36이다. 오차는 ±4.4%p에서 ±5.1%p로 넓어진다. 연령대별 찬성이 70%, 50%, 30%라 가정하면 가중 전 60%, 가중 후 52%다. 가중치를 주면 값도 바뀌고 오차도 커진다. 둘 다 보고에 쓴다.

## 집단 간 차이를 읽을 때

규칙: 두 집단의 비율 차이는 차이의 신뢰구간으로 읽는다. 구간이 0을 포함하면 차이가 있다고 단정하지 않는다.

- 식: `d = p1 - p2`, 구간 `d ± z·√(p1(1-p1)/n1 + p2(1-p2)/n2)`. 가상 예는 A 60%, B 52%(차이 8%p)이다.
- 각 집단의 오차 범위가 겹쳐도 차이가 유의할 수 있다. 400명 대 300명은 55.2-64.8%와 46.4-57.7%로 겹치지만 차이의 구간은 0을 제외한다.
- 차이의 오차는 각 집단 오차보다 크다. 각 400명이면 ±4.9%p이지만 차이는 ±6.9%p다.
- 8%p 차이를 80% 검정력으로 가르려면 집단당 약 605명이 필요하다(60% 대 52%, 양측 5%). A/B 테스트의 표본 수 식과 같은 방식이다.

### 하위 집단으로 나눌 때

규칙: 교차 분석은 칸 하나의 응답 수로 오차를 본다. 칸이 작으면 보고하지 않는다.

| 분석 대상 | 응답 수 | 오차 범위(p 0.5, 95%) |
|---|---|---|
| 전체 | 400 | ±4.9%p |
| 하위 집단 | 200 | ±6.9%p |
| 하위 집단 | 100 | ±9.8%p |
| 하위 집단 | 40 | ±15.5%p |

전체가 400명이어도 응답자의 10%인 집단은 40명이라 ±15.5%p다.<Ref n={4} /> 보여 줄 칸의 최소 응답 수는 설문 전에 정한다. 오차가 결정에 필요한 차이보다 크면 칸을 합치거나 "참고용"으로 표시한다. 하위 집단별 결과가 필요하면 그 집단의 표본 수를 따로 계획한다.

## NPS 같은 점수 지표를 읽을 때

규칙: 점수는 정의를 고정해 같은 질문, 같은 척도, 같은 대상끼리만 비교한다. 점수만 보고하지 말고 분포와 n을 같이 쓴다.

| 항목 | 이 글이 쓰는 정의 |
|---|---|
| 질문 | 우리를 친구나 동료에게 추천할 가능성은? |
| 척도 | 0점부터 10점 |
| 추천 | 9점과 10점 |
| 중립 | 7점과 8점 |
| 비추천 | 0점부터 6점 |
| 식 | `NPS = 추천 비율(%) - 비추천 비율(%)`, 범위 -100에서 +100<Ref n={7} /> |

<Figure caption="NPS가 같아도 분포는 다르다. 점수 하나로는 A와 B를 구분할 수 없다. 응답 200명은 가정이다.">
  <NpsShapes />
</Figure>

- 중립은 식에서 빠진다. 응답 10명이 8점에서 9점으로 올라가면 NPS는 5점 오르지만(n=200) 만족이 크게 달라진 것은 아니다.
- NPS의 오차도 구해야 한다. `추천 p`, `비추천 d`이면 분산은 `(p + d - (p-d)²)/n`이다. 추천 40%, 비추천 30%일 때 95% 오차는 n이 100이면 ±16.3점, 200이면 ±11.5점, 500이면 ±7.3점, 1,000이면 ±5.1점이다.
- n=200에서 +10이 +15가 되어도 오차 범위 안이다. 목표를 몇 점 올렸다는 보고는 구간과 같이 쓴다.
- 만족도 평균도 같다. 평균만 쓰지 말고 분포를 같이 보고, 계산식을 적는다.

## 결과를 보고할 때

규칙: 숫자 옆에 조건을 붙인다. 조건이 없으면 읽는 사람이 결과를 과신한다.

| 병기 항목 | 쓰는 내용 |
|---|---|
| 유효 응답 수 n | 보낸 수와 응답률도 같이 |
| 대상과 추출 방법 | 명단 무작위 추출인지, 자발적 참여인지 |
| 조사 기간 | 시작일과 종료일 |
| 조사 방법 | 이메일, 앱 팝업, 전화 등 |
| 오차 범위 | 확률 표본만, 신뢰수준과 함께. 비확률은 "산출 불가" |
| 가중치 | 가중 여부와 쓴 변수 |
| 문항 원문 | 보기와 순서 포함 |

| 나쁜 보고 | 고친 보고(가상) |
|---|---|
| 고객 72%가 신기능에 만족 | 고객 명단에서 무작위로 뽑은 1,200명에게 이메일 발송, 9월 1일부터 7일까지, 응답 385명(응답률 32.1%). 만족 72%, 95% 오차 ±5%p(무응답 편향은 반영 안 됨) |
| SNS 투표로 78%가 B안 선호 | SNS 링크 응답 n=640, 자발적 참여라 오차 범위 산출 불가. 응답자 경향이며 전체 고객의 비율이 아니다 |

## 점검 체크리스트

- 설문이 바꿀 결정과 대상 집단이 한 줄로 적혀 있는가.
- 모든 문항에 "이 답이 바꿀 결정"이 있는가.
- 한 문항에 한 가지만 묻는가. 기간이 숫자인가. 보기가 겹치지 않고 빠짐없는가.
- 척도 방향과 길이가 통일되어 있고 양끝 라벨이 있는가.
- 민감 문항이 뒤에 있고 응답 안 함 보기가 있는가.
- 필요한 표본 수를 오차 범위와 신뢰수준으로 계산했고, 응답률을 가정해 발송 수를 정했는가.
- 모집 방식이 확률 표본인지 비확률 표본인지 구분하고 그에 맞게 오차 범위를 썼는가.
- 집단 비교는 차이의 구간으로 하고, 하위 집단 칸의 응답 수를 확인했는가.
- NPS는 분포와 n, 오차를 함께 보고했는가.
- 보고에 n, 조사 기간, 방법, 오차 범위(또는 산출 불가), 가중 여부가 있는가.
