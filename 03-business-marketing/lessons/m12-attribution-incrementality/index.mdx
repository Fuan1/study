## 증분 효과를 계산할 때

규칙: 구매율 차이에서 시작하고 구간과 함께 쓴다. 가상 값은 처치 200,000명 중 4,800명, 대조 50,000명 중 1,080명 구매, 객단가 50,000원, 처치군 광고비 1,200만원, 플랫폼 귀속 전환 1,900건이다.

```python
import math
n1, c1 = 200000, 4800   # 처치
n0, c0 = 50000, 1080    # 대조
p1, p0 = c1 / n1, c0 / n0
d = p1 - p0
se = math.sqrt(p1*(1-p1)/n1
               + p0*(1-p0)/n0)
lo, hi = d - 1.96*se, d + 1.96*se
inc = c1 - c0 * n1 / n0
print(round(inc))
print(round(lo*n1), round(hi*n1))
```

출력은 480, 192, 768이다.

| 지표 | 식 | 점추정 | 95% 구간 |
|---|---|---|---|
| 구매율 차이 | 2.40% − 2.16% | 0.24%p | 0.10%p에서 0.38%p |
| 리프트 | p처치 ÷ p대조 − 1 | 11.1% | 4.1%에서 18.6% |
| 증분 구매 | 4,800 − 1,080 × 4 | 480건 | 192에서 768건 |
| 증분 ROAS | 480 × 50,000 ÷ 1,200만 | 2.0 | 0.8에서 3.2 |
| 귀속 ROAS | 1,900 × 50,000 ÷ 1,200만 | 7.9 | 보고값 |

두 비율의 z 검정(비합동 표준오차)은 z=3.27, p=0.0011이고 리프트 구간은 로그 비의 근사다. 공헌이익률 30%(가정)이면 손익분기 ROAS 는 3.3이다. 증분 ROAS 구간 전체가 그 아래라 이 예산에서는 손해일 가능성이 높다. 귀속 ROAS 7.9만 봤다면 증액했을 것이다.

## 표본과 기간을 정할 때

규칙: 시작 전에 검출하려는 최소 효과(MDE)로 표본을 계산한다. 비율 지표의 군당 표본은 `n = 2·p·(1−p)·(1.96+0.84)² ÷ d²`(p는 두 군 평균 비율, 검정력 80%, 양측 5%)이고 근거는 d10에서 본다.

| 상대 리프트(대조 2.16%, 가정) | 군당 표본(균등) |
|---|---|
| 5% | 291,370 |
| 10% | 74,578 |
| 20% | 19,511 |

- 이 예의 리프트 11.1%는 균등 배정이면 군당 60,721명(합 121,442명)이고, 80 대 20이면 대조 36,778명과 처치 147,109명(합 183,887명)으로 합이 1.5배다.
- 기간은 표본이 차는 날과 광고를 본 뒤 구매까지 걸리는 시간 중 긴 쪽으로 잡고 7일의 배수로 올린다(관행). 광고 중단 테스트는 효과가 늦게 사라질 수 있어 더 길게 잡는다.

## 대조군 오염과 시즌을 점검할 때

규칙: 결과를 읽기 전에 아래를 확인한다. 하나라도 걸리면 구간을 믿지 말고 설계를 고쳐 재실험한다.

| 점검 | 확인 방법 | 기준 |
|---|---|---|
| 사전 기간 균형 | 시작 전 4주 구매율을 두 군에서 비교 | 차이의 구간이 0을 포함 |
| 대조군 노출 | 대조군의 광고 노출 수, 다른 캠페인·리타게팅 목록 포함 여부 | 노출 0 |
| 처치군 도달 | 처치군 중 실제 노출 비율 | 낮으면 증분이 작게 나온다 |
| 동시 이벤트 | 기간 중 세일, 가격 변경, 명절, 다른 채널 변경 | 두 군에 같이 걸려야 한다 |

## 귀속 숫자와 증분이 크게 다를 때

규칙: 이미 사려던 고객을 데려가는 광고(브랜드 검색, 리타게팅, 기존 고객 대상 이메일)는 귀속이 크고 증분이 작다. 증분 ROAS 구간을 손익분기와 비교해 정한다.

가상 예: 브랜드명 검색 광고를 지역 20개 중 무작위 10개에서 4주 중단했다. 중단 지역의 사전 4주 귀속 전환은 3,000건, 광고비 900만원, 객단가 50,000원이다. 지표는 지역별 전체 주문이고, 변화율은 시험 기간 주문 ÷ 사전 기간 주문이다.

| 지표 | 값 |
|---|---|
| 중단 지역 주문 전후 | 13,331 → 13,497건(+1.2%) |
| 유지 지역 평균 변화율 | +4.8% |
| 중단 지역 평균 변화율 | +1.3% |
| 차이 | −3.5%p(95% 구간 −4.3%p에서 −2.6%p) |
| 광고가 만든 주문 | 463건(352에서 573), 귀속 전환의 15% |

<Figure caption="귀속 3,000건 중 광고가 만든 주문은 약 15%이고 ROAS 는 16.7에서 2.6으로 내려간다.">
  <BrandSearchGap />
</Figure>

- 중단 지역만 전후로 보면 주문이 1.2% 늘어 광고가 필요 없어 보인다. 같은 기간 유지 지역이 4.8% 늘었다. 시즌 증가는 대조군으로 뺀다.
- 증분 ROAS 2.6(2.0에서 3.2)은 손익분기 3.3보다 낮다. 감액을 검토한다. 증분이 작다고 광고가 쓸모없는 것은 아니다.
- 경쟁사가 내 브랜드 키워드에 입찰하면 광고를 껐을 때 잃는 주문이 더 클 수 있다. 경쟁사 입찰 여부를 기록한다.
- 지역 20개는 적어 구간이 넓다(지역별 변화율 평균 차이의 Welch t 구간).

## 마케팅 믹스 모델링이 필요한지 정할 때

규칙: 채널이 여러 개이고 실험하기 어려운 채널(TV, 오프라인)이 예산 상당 부분을 차지하며 매출·지출의 긴 시계열이 있을 때만 쓴다. Google 의 Meridian 문서는 주 단위 데이터를 권하고 지역 단위 모델은 최소 2년, 전국 단위 모델은 3년치로 안내한다<Ref n={10} />. 이 조건이 안 되면 증분 실험이 먼저다.

## 마케팅 리포트를 쓸 때

규칙: 지표, 변화, 원인, 결정, 다음 실험 순서로 쓴다(변화 칸에는 귀속 7.9 대 증분 2.0처럼 비교 대상 대비를 쓴다). 귀속과 증분은 구분해 쓰고 기준(모델, 창, 기간)을 붙인다. 숫자 표기와 불확실성 표현은 d13에서 본다.

| 칸 | 쓸 내용 | 예(가정) |
|---|---|---|
| 지표 | 정의와 기준 | 증분 ROAS 2.0(95% 구간 0.8에서 3.2), 처치 200,000 대 대조 50,000 |
| 원인 | 확인한 것과 못 한 것 | 합계 ÷ 실제 1.41 확인, 대조군 노출 0 확인 |
| 결정 | 무엇을 하고 기준은 무엇인가 | 증액 보류, 구간이 손익분기 3.3 아래라 감액 검토 |
| 다음 실험 | 가설, 기간, 지표, 표본 | 대조군 확대 재실험, 표본 계산 후 4주 |

## 증상으로 찾기

| 증상 | 원인 | 처방 |
|---|---|---|
| 플랫폼 합이 실제 주문보다 크다 | 중복 귀속, 긴 창, 조회 기반 | 주문 ID 내부 장부, 합계 ÷ 실제 |
| 모델을 바꾸면 채널 순위가 뒤집힌다 | 모델 가정의 차이 | 한 모델로 고정, 뒤집힌 채널은 실험 |
| 같은 출처가 보고서에 둘로 나온다 | 대소문자·표기 불일치 | 소문자 규칙, 값 목록 |
| 귀속 ROAS 는 높은데 광고를 꺼도 매출이 안 줄었다 | 이미 살 고객을 귀속 | 대조 지역 중단 테스트, 손익분기와 비교 |
| holdout 구간이 0을 포함하고 넓다 | 표본 부족 | 표본 재계산(d10), 기간 연장 |
| 광고를 끈 지역 매출이 올랐다 | 시즌 효과 | 대조 지역과의 차이로 판단 |

## 점검 체크리스트

- 플랫폼 합계 ÷ 실제 주문을 계산했고 전환 정의·창·조회 포함 여부를 기록했는가.
- 주문 하나가 채널 하나에만 배정되는 내부 장부가 있고 결정용 모델이 고정돼 있는가.
- UTM 이 소문자, 목록 값, 생성 도구로 만들어졌고 내부 링크에 없는가.
- 실험 전에 배정 방식, MDE, 표본, 기간, 판정 기준을 문서로 고정했는가.
- 사전 기간 균형, 대조군 노출 0, 동시 이벤트를 확인했는가.
- 증분 ROAS 를 95% 구간과 함께 쓰고 손익분기 ROAS 와 비교했는가.
