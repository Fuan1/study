## 헤드라인을 쓸 때

규칙: 헤드라인은 구체적 결과 하나만 약속한다. 두 번째 약속은 헤드라인 아래 문장에 둔다.

| 규칙 | 나쁜 예 | 고친 예 |
|---|---|---|
| 구체적 결과 | 정산 걱정 끝 | 월말 정산, 8시간에서 1시간으로 |
| 한 문장 한 약속 | 정산도 재고도 세금도 한 번에 해결 | 월말 정산을 1시간으로 |
| 고객의 말 | 정산 프로세스 최적화 솔루션 | 정산표 직접 만들기 그만 |
| 숫자에 근거 | 정산 시간 87% 단축 | 시범 20곳 평균, 8시간에서 1시간(자체 측정, 2026년 3월) |

숫자를 쓸 때는 세 가지를 같이 쓴다. 헤드라인에 다 못 넣으면 바로 아래 한 줄에 둔다.

- 모수: 몇 명 중 몇 명인가. 비율은 분자와 분모를 같이 쓴다. 가정: 90일간 가입한 1,200명 중 504명이 30일 안에 재주문했다면 42%다. 95% 구간은 39.2%에서 44.8%이다.<Ref n={2} />
- 기간: 언제부터 언제까지 쟀는가.
- 출처: 자체 집계인가, 외부 조사인가. 측정 방법이 한 줄로 설명되는가.

- 하지 마라: 중앙값이나 최고 사례를 "평균"이라고 쓰지 마라. 평균이라고 쓰면 평균을 계산해 보여 준다.
- 하지 마라: 한 문장에 약속 둘을 넣지 마라. 읽는 사람은 하나만 기억하고, 어느 쪽인지는 고르지 못한다.

## 증거를 붙일 때

규칙: 주장마다 증거 하나를 붙이고, 증거의 종류에 맞는 표기 규칙을 따른다.

| 증거 | 쓰는 규칙 | 쓰지 마라 |
|---|---|---|
| 수치 | 분자·분모·기간·측정 방법을 쓴다 | 모수가 작은데 비율만 크게 쓴다 |
| 후기 | 원문 그대로, 고른 기준을 안다 | 좋은 것만 골라 전체 평가처럼 쓴다 |
| 사례 | 고객 동의, 시작 상태, 기간, 결과 | 예외적 성과를 보통 결과처럼 쓴다 |
| 수상·인증 | 수여 기관, 연도, 부문 | 기관·연도 없이 로고만 붙인다 |

후기·추천에 협찬이나 대가가 있을 때의 표시 의무, 수상·인증 표기의 법적 기준은 m13에서 다룬다.

같은 96%라도 모수에 따라 믿을 수 있는 범위가 다르다. 25명 중 24명이면 95% 구간이 80.5%에서 99.3%이고, 500명 중 480명이면 93.9%에서 97.4%이다.

<Figure caption="같은 96%도 모수가 작으면 구간이 넓다. 모수 없는 비율은 증거가 되지 못한다.">
  <EvidenceInterval />
</Figure>

```python
import math

def wilson(k, n, z=1.96):
    p = k / n
    d = 1 + z * z / n
    c = (p + z * z / (2 * n)) / d
    h = z * math.sqrt(p * (1 - p) / n
        + z * z / (4 * n * n)) / d
    return c - h, c + h

print(wilson(24, 25))
```

증거 없는 주장은 아래 세 질문으로 거른다. 하나라도 답이 없으면 주장을 빼거나 사실로 낮춘다.

- 누가, 언제, 무엇으로 쟀는가.
- 무엇과 비교했는가(비교 대상이 없으면 "빠르다", "싸다"는 말이 안 된다).
- 고객이 직접 확인할 수 있는가(체험, 공개 사례, 화면).

## 과장 표현을 점검할 때

규칙: 최상급, 절대 표현, "유일", 타사 비교는 객관적 근거 자료가 있을 때만 쓴다. 근거는 문구를 내보내기 전에 파일로 보관한다. 이 표는 점검 기준이며 법률 자문이 아니다. 조문과 허용 범위는 m13에서 확인한다.

|---|---|---|---|
| 최상급 | 업계 1위, 최고 | 기준·조사 기관·기간·비교 대상이 있는가 | 측정한 사실로 낮춘다 |
| 절대 | 100% 만족, 무조건, 완벽 | 예외 없음을 보일 수 있는가 | 범위를 쓴다(시범 20곳 중 19곳) |

| 비교 | 타사보다 2배 빠르다 | 비교 대상과 조건을 밝히는가 | 조건을 같이 쓴다 |
| 결과 보장 | 매출 두 배 보장 | 고객마다 같은 결과가 나오는가 | 사례의 범위로 쓴다 |

## 메시지를 시험할 때

규칙: 값싼 방법으로 이해를 확인하고, 비싼 방법으로 행동을 확인한다. 각 방법이 답하는 질문만 묻는다.

| 방법 | 답하는 질문 | 표본과 계산 | 한계 |
|---|---|---|---|
| 고객 인터뷰 | 고객이 문제를 어떤 말로 하나 | 5에서 8명(관행). 겪는 비율 30%면 5명 중 1명 이상 83.2% | 말과 행동이 다르다. 선호 예측 못 함 |
| 5초 이해도 | 5초 뒤 무엇을 파는지 쓸 수 있나 | 20명 중 14명이면 70%, 구간 48.1%에서 85.5% | 믿음·행동은 못 잼. 인위적 상황 |
| 설문 | 어느 문구가 더 이해되고 끌리나 | 응답자 수와 구성이 결과를 좌우 | 선택 응답은 행동이 아니다. 순서 편향 |
| 광고 소재 테스트 | 어느 문구가 클릭을 얻나 | 클릭률 2.0%에서 2.5%를 가르려면 소재당 노출 13,811, 2.0%에서 3.0%면 3,827 | 클릭이 전환은 아니다. 낚시 제목이 이긴다 |
| A/B 테스트 | 어느 문구가 전환을 올리나 | 전환율 5%에서 7.5%를 가르려면 변형당 방문 1,472 | 트래픽이 필요하다. 한 번에 한 요소 |

표본은 가정 계산이다. 문제를 겪는 비율 p와 인터뷰 n명이면 "한 명 이상 만날 확률"은 `1-(1-p)^n`이고 독립을 가정한다. 비율 비교 표본은 `2·p̄(1-p̄)(1.96+0.84)²/δ²`이다(양측 5%, 검정력 80%, p̄는 두 비율의 평균, δ는 차이). 14/20 같은 비율은 위 Wilson 구간으로 읽는다.

- 순서는 인터뷰나 5초 테스트로 방향을 잡고, 소재 테스트로 반응을 보고, A/B로 행동을 확정한다. 광고 소재 판정 지표와 예산은 m08을 본다.
- 소재 테스트에서 이긴 문구는 전환율까지 같이 본다. 클릭만 높은 문구는 약속을 부풀렸을 수 있다.
- 5초 테스트는 "어떤 제품이고 누구용인가"만 묻는다. "좋은가"를 묻지 않는다.

## 증상으로 찾기

클릭이 낮다, 전환이 낮다의 기준은 업계 평균이 아니라 자기 이전 값과 손익분기다(m08).

|---|---|---|
| 노출은 되는데 클릭이 낮다 | 제목이 기능이고 결과가 없다. 대상이 안 맞다 | 검색어에 결과를 이은 제목을 새로 쓰고 소재를 시험 |
| 클릭은 되는데 전환이 안 된다 | 랜딩에서 약속이 바뀜. 대상 밖 사람이 클릭 | 약속 대조표, 랜딩 첫 화면에 광고 문구 그대로 |
| 5초 테스트에서 뭘 파는지 못 맞힌다 | 내부 용어, 약속이 여러 개 | 한 약속으로 줄이고 고객의 말로 |
| 이해는 하는데 믿지 않는다 | 증거 칸이 없거나 모수 없는 숫자 | 모수·기간·출처가 있는 증거와 사례 |
| 가입을 시작하고 중간에 나간다 | 가입 단계에서 조건이 새로 나온다 | 조건을 앞 화면으로 옮기고 대조 |
| 소재 테스트 승자가 매출은 못 올린다 | 클릭용 문구가 약속을 부풀림 | 판정을 전환까지 내리고 약속을 제품 범위로 |

## 점검 체크리스트

- 결과 칸이 고객의 단위(시간, 원, 건, 일)로 쓰였는가.
- 문구가 누구에게, 문제, 결과, 증거, 행동의 순서를 지키고 빈 칸이 없는가.
- 헤드라인이 약속 하나인가. 약속이 둘이면 하나를 아래로 내렸는가.
- 모든 숫자에 모수, 기간, 출처가 있는가.
- 최상급·절대·유일·비교 표현의 근거 자료가 보관돼 있는가(m13).
- 검색 광고 제목·설명이 글자 수 한도 안이고, 제목이 서로 조합돼도 말이 되는가.
- 광고, 랜딩, 가입 화면의 가격·기간·조건·대상·행동이 같은가.
- 문구를 이해(인터뷰·5초)와 행동(소재·A/B)으로 나눠 확인했는가.
